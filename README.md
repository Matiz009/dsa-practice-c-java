# DSA Practice in C & Java

Data structures and algorithms practice, written in C and Java.

## Topics

| Category | Folders |
|---|---|
| Basics | `first_program`, `loops_and_conditionals`, `functions`, `Patterns`, `Recursion`, `cgpaCalculator` |
| Arrays & strings | `Arrays`, `2D_Arrays`, `arrays_and_arrayList`, `Strings_and_StringBuilder` |
| Linear structures | `Linked List`, `LinkedLists`, `Stack`, `Stacks`, `queue`, `Queues` |
| Trees | `Binary_Trees` |
| Algorithms | `Searching_Algos`, `Sorting_Algos` |

## Running

```bash
gcc Arrays/isEmpty.c -o isEmpty && ./isEmpty
```

Java folders are IntelliJ projects; open them in IntelliJ or compile with `javac`.
